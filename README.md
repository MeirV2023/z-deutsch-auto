# 🚀 Z-DEUTSCH: AUTO — Космический тренажёр немецких слов в стиле ZType

Интерактивная браузерная аркада в духе [ZType](https://zty.pe/) для изучения немецких слов по теме **Auto (Автомобиль, Дорога, Путешествия, Страхование)**.

## ✨ Особенности
- **Аркадный стартовый экран:** живые космические туманности, ранг пилота, рекорды и корабль на автопилоте, ведущий демонстрационный бой выбранным оружием прямо на фоне главного меню.
- **5 видов космического оружия (клавиши `1`–`5`):**
  1. `⚡ Плазма` — сдвоенные плазменные импульсы с нарастающей комбо-гармоникой.
  2. `🔴 Рельсотрон` — пробивной гиперлуч с мощным саб-басом, ударными кольцами и сильной отдачей.
  3. `🌩️ Тесла` — ветвящаяся электрическая дуга с треском разряда и цепными искрами.
  4. `🚀 Ракеты` — самонаводящиеся микро-ракеты с дымным шлейфом и микро-детонацией.
  5. `🎵 Неон-Синт` — призматический Synthwave-лазер, превращающий быструю печать в мелодию!
- **Многослойный синтез звука (Web Audio API 2.0):** тактильный щелчок клавиши, стерео-панорамирование по положению слова, комбо-аккорды и гиперпрыжок при старте миссии.
- **Студийная озвучка `gemini-3.8-flash-tts` / `gemini-3.8-flash-lite-tts`:** живое немецкое произношение через Gemini 3.8 Interactions API с фоновой предзагрузкой (`0 мс` задержки при взрыве), локальным кэшем `IndexedDB` и серверным CDN-кэшированием на Vercel (`/api/tts`).
- **73 немецких слова** разбиты на 6 тематических подуровней + финальный марафон **«AUTO»**.
- **Полная локализация RU / עברית:** Русский (`🇷🇺 RU`), Иврит (`🇮🇱 עברית`, RTL) или оба перевода одновременно (`🇷🇺+🇮🇱`).
- **Мобильная космическая клавиатура ZType** для удобной игры на смартфоне.

## 🎙️ Настройка озвучки Gemini 3.8 TTS на Vercel
1. В панели проекта на **Vercel** перейдите в **Settings → Environment Variables**.
2. Добавьте переменную `GEMINI_API_KEY` со значением вашего ключа из Google AI Studio и нажмите **Redeploy**.
3. Серверная функция `api/tts.js` автоматически синтезирует аудио через `gemini-3.8-flash-tts` и кэширует WAV-ответы в глобальном Edge CDN Vercel.
4. *(Альтернативно)* Ключ можно вставить прямо в игре через кнопку **`🎙️ Gemini 3.8 TTS`** — он сохранится локально только в вашем браузере (`localStorage`). Если ключ не указан, игра автоматически использует встроенный немецкий синтезатор браузера (`de-DE`).
