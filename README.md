# 🚀 Z-DEUTSCH: AUTO — Космический тренажёр немецких слов в стиле ZType

Интерактивная браузерная игра в стиле [ZType](https://zty.pe/) для изучения немецких слов по теме **Auto (Автомобиль, Дорога, Путешествия, Страхование)**.

## ✨ Особенности
- **73 немецких слова** разбиты на 6 тематических подуровней + полный марафон **«AUTO»**.
- **Выбор языка перевода:** Русский (`🇷🇺 RU`), Иврит (`🇮🇱 עברית`) или оба языка одновременно (`🇷🇺+🇮🇱`).
- **Перевод при взрыве:** когда слово полностью напечатано, оно взрывается, а на месте взрыва всплывает голограмма с переводом и звучит немецкое произношение (`de-DE`).
- **Настройка скорости:** `0.5x`, `0.7x`, `1.0x`, `1.35x`.
- **Умный ввод немецких букв:** умлауты `ä, ö, ü, ß` можно вводить как немецкими клавишами, так и обычными латинскими `a, o, u, s` (`ae, oe, ue, ss`).
- **Блиц-тест после каждого уровня** и журнал сбитых слов справа.

## 🚀 Запуск на Vercel
Проект полностью статический (`index.html`, `styles.css`, `words.js`, `game.js`) и готов к деплою на Vercel в один клик (Framework Preset: `Other`).
