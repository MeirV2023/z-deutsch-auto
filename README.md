# 🚀 Z-LINGO — Космический языковой шутер (DE · EN · ES | Gemini 3.8 TTS | Anki .apkg)

Интерактивная браузерная аркада в духе ZType для изучения **немецкого, английского и испанского языков** с полной локализацией интерфейса на **русский (`🇷🇺 RU`), английский (`🇬🇧 EN`) и иврит (`🇮🇱 עברית`, RTL)**.

## ✨ Ключевые возможности
- **Живой промо-бой на Главной и Боевая Академия:** космический истребитель, авто-замедление длинных составных слов, защита от наложения капсул и 3 режима тренировки (*Печатать · Слушать · Переводить*).
- **6 видов космического оружия с прокачкой за выученные слова (`1`–`6`):** `⚡ Плазма`, `🌀 Грави-волна`, `🔴 Рельсотрон`, `🚀 Ракеты`, `🌩️ Тесла`, `🎵 Неон-Синт`.
- **Полноэкранная страница «Мои колоды» и импорт Anki (`.apkg`):** клиентский разбор архивов Anki 2.0 / 2.1 / 23.10+ (`SQLite3` + `Zstd`), авто-распознавание полей карточек, хранение в `IndexedDB` без нагрузки на сервер и адаптивный мобильный интерфейс (`<= 768px`).
- **Студия Супер-Админа (`👑 Админ`):** создание глобальных курсов из книжных списков, авто-перевод на RU/EN/HE через `gemini-3.8-flash` и публикация для всех игроков через GitHub/Vercel.
- **Студийная озвучка `gemini-3.8-flash-tts` / `gemini-3.8-flash-lite-tts`:** мгновенное произношение при взрыве слова с кэшированием в `IndexedDB` и Vercel Edge CDN (`/api/tts`).

## 🏗️ Модульная архитектура (SOLID)
Код проекта разделён на независимые ES-модули (`src/`), тематические таблицы стилей (`styles/01..08`) и серверные утилиты (`api/_lib/`). Подробное описание слоёв и контрактов — в [ARCHITECTURE.md](./ARCHITECTURE.md).

- Локальный запуск: дважды кликните `start-local.bat` или выполните `python -m http.server 8080`.
- Статическая проверка архитектуры и модулей: `python scripts/verify_project.py`.
